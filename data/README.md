# Runtime data

This directory is reserved for app-ready data packs loaded by the runtime. The authoritative handoff data remains in `02_DATA/` and `03_REWARDS_BOSSES/` until a later stage adds validated import/copy tooling.

- `vocabulary/`: vocabulary packs
- `stories/`: thinking-story packs
- `tasks/`: general, exercise, and chore task packs
- `rewards/`: reward definitions
- `bosses/`: boss definitions
- `copy/`: reusable fixed interface copy; never canonical task, story, Boss, reward, or vocabulary content

Do not treat these empty runtime folders as authoritative content.
