# Real Life Quest｜ART BIBLE v1.0

## 文件定位
本文件為 **Real Life Quest** 的正式美術聖經（Art Bible）與角色一致性規格。
後續所有角色圖、任務圖、Boss 圖、背景圖、UI 插畫、宣傳圖，都必須以本文件為最高視覺規範。
若未來有新圖要製作，應優先遵守本文件，而不是自由發揮。

---

# 1. 專案視覺核心

## 1.1 世界觀定位
Real Life Quest 是一款面向約 8 歲兒童的「現實生活 RPG」。
它不是戰鬥導向遊戲，而是把閱讀、英文、家事、運動、耐心、思考、合作等真實任務，轉化為可見的冒險體驗。

## 1.2 整體氣質
必須同時具備以下感受：

- 明亮
- 安全
- 溫暖
- 活潑
- 可愛
- 童趣
- 冒險感
- 成長感
- 鼓勵感
- 不壓迫

## 1.3 避免的氣質
以下風格不符合本專案：

- 過暗、陰森、恐怖
- 過度寫實
- 過度幼兒化（太像 3~4 歲向）
- 過度電競化
- 過度二次元戀愛遊戲化
- 過度複雜、華麗到影響閱讀
- 太銳利、太兇、太成人感
- 過度科幻、機械感過重
- 太像戰鬥 RPG 或抽卡手遊

# 2. 美術風格總規範

## 2.1 插畫風格
- 兒童友善的高品質數位插畫
- 半扁平＋柔和立體感
- 線條可有可無，但輪廓必須清楚
- 光影柔和，不可太硬
- 具遊戲角色感，但保有教育產品的乾淨度
- 可愛且清楚，適合放入 UI 介面

## 2.2 角色比例
- Q版偏輕，不可太誇張
- 頭稍大、眼睛偏大
- 四肢清楚可辨識
- 身體比例自然，不可變形過頭
- 必須一眼就能看出姿勢與動作

## 2.3 渲染要求
- 顏色乾淨、飽和但不刺眼
- 陰影柔和
- 有一定質感，但不可過度寫實
- 材質表現偏柔軟
- 布料、毛髮、皮革、金屬配件可略帶質感
- 角色邊緣清楚，方便去背與 UI 疊加

## 2.4 背景風格
- 背景可簡化
- 若為資產圖，優先透明背景
- 若為場景圖，層次清楚，保留足夠留白
- 不要讓背景搶走角色主體

# 3. 色彩系統

## 3.1 主色方向
整體色彩應接近：

- 天空藍：首頁、學習感、清新感
- 草地綠：成長、任務、自然
- 金黃色：獎勵、寶箱、成功
- 暖橘色：活力、角色重點、冒險溫度
- 米白色：卡片、紙張、柔和 UI 背景
- 木棕色：木牌、章節牌、冒險標示

## 3.2 角色共通視覺錨點
以下是 Real Life Quest 的角色辨識重點：

- 暖色系圍巾（偏橘紅）
- 指南針徽章
- 冒險者風格
- 溫暖、親切的大眼表情
- 柔和、正向、鼓勵式表情語言

# 4. 正式角色規格

## 4.1 男主角｜正式主角規格

### 角色定位
- 小小冒險家
- 勇敢、開朗、願意嘗試
- 代表「開始做」「主動挑戰」

### 外觀規格
- 年齡視覺：約 8～10 歲
- 髮型：棕色短髮，乾淨、活潑、帶少量層次
- 臉型：圓潤偏可愛
- 眼睛：大眼，明亮，友善，有精神
- 膚色：健康自然的淺膚色
- 上衣：米白或淺卡其冒險者上衣
- 下身：棕色或深卡其短褲 / 短下裝
- 配件：橘紅色圍巾、指南針徽章、小背包
- 鞋子：簡單冒險鞋 / 靴，棕色系
- 風格印象：可靠、可愛、乾淨、有冒險感

### 必須保留
- 棕色短髮
- 橘紅色圍巾
- 指南針元素
- 米白＋棕色系服裝基調
- 8～10 歲的兒童感
- 開朗親切的整體表情

### 可變動
- 小幅度表情變化
- 不同姿勢與動作
- 手持道具（書本、鉛筆、跳繩、掃把等）
- 背包有時可隱藏
- 鞋子細節可簡化

### 不可變動
- 不可變成長髮
- 不可改成冷色主服裝
- 不可取消圍巾與指南針這兩個核心辨識點
- 不可變成太成熟少年感
- 不可變成戰鬥型裝甲角色

---

## 4.2 女主角｜正式主角規格

### 角色定位
- 元氣冒險家
- 聰明、自信、溫暖、願意學習
- 代表「思考」「成長」「實踐」

### 外觀規格
- 年齡視覺：約 8～10 歲
- 髮型：棕色中長髮或長髮，整齊、自然、有活力
- 臉型：圓潤可愛
- 眼睛：大眼，溫暖明亮
- 膚色：健康自然的淺膚色
- 上衣：米白或淺卡其冒險者上衣 / 洋裝改良式冒險服
- 下身：短裙或短褲型冒險裝，棕色 / 卡其色系
- 配件：橘紅色圍巾、指南針徽章、小背包
- 鞋子：簡單冒險鞋 / 短靴
- 風格印象：親切、有活力、聰明、可愛

### 必須保留
- 棕色中長髮 / 長髮
- 橘紅色圍巾
- 指南針元素
- 米白＋棕色系服裝基調
- 8～10 歲的兒童感
- 自信溫暖的表情

### 可變動
- 髮尾微變化
- 小配件細節可簡化
- 動作、姿勢、手持物件可變
- 背包可視畫面需求隱藏

### 不可變動
- 不可改成高冷成熟少女風
- 不可偏偶像、戀愛遊戲風
- 不可取消圍巾與指南針
- 不可改成冷色系主服裝
- 不可明顯年齡上升

---

## 4.3 狐狸夥伴｜正式夥伴規格

### 角色定位
- 主角們的冒險夥伴
- 活潑、忠誠、可愛、鼓勵感強
- 是孩子最容易建立情感連結的非人角色

### 外觀規格
- 物種：Q版橘狐
- 站姿：以四腳著地為正式基本姿勢
- 毛色：暖橘色為主，腹部與尾巴白色，局部棕色點綴
- 耳朵：大耳朵，內側帶淺色絨毛
- 眼睛：大眼，明亮，極具親和力
- 尾巴：蓬鬆、偏大、強辨識度
- 配件：橘紅色圍巾、指南針徽章
- 表情：開心、靈動、討喜
- 風格印象：像吉祥物，但不是嬰兒化寵物

### 必須保留
- 橘色主毛色
- 大尾巴
- 橘紅圍巾
- 指南針徽章
- 四腳站立的基本結構
- 明亮大眼與可愛表情

### 可變動
- 尾巴擺動方向
- 臉部表情
- 身體角度
- 坐姿 / 趴姿 / 小跳躍等延伸姿勢

### 不可變動
- 不可把四肢畫錯
- 不可出現多餘肢體
- 不可把正式基本型改成擬人二足站立
- 不可變成犬、貓或其他動物感
- 不可取消圍巾與指南針

# 5. 角色一致性規則

## 5.1 角色一致性高優先項
未來所有角色圖，以下項目必須優先一致：

1. 臉型
2. 眼睛形狀與氣質
3. 主配色
4. 圍巾
5. 指南針徽章
6. 年齡感
7. 服裝輪廓
8. 狐狸耳朵與尾巴輪廓

## 5.2 一致性允許範圍
可接受少量變化：
- 動作變化
- 角度變化
- 表情變化
- 手持物不同
- 因畫面裁切造成局部不見

不可接受的漂移：
- 臉突然變太成熟
- 圍巾顏色跑掉
- 指南針消失
- 男主角髮型不同像另一人
- 女主角服裝完全換世界觀
- 狐狸比例每張都不同
- 狐狸站姿解剖錯誤

# 7. 任務插圖規格

## 7.1 運動任務圖
應以「教學友善、動作清楚」為主。

規則：
- 角色動作必須正確
- 孩子看了要知道怎麼做
- 一張圖只表達一個主要動作
- 可搭配簡化地面或道具
- 不可畫太複雜背景
- 角色可使用男主角、女主角，或以中性示意圖為主

## 7.2 家事任務圖
規則：
- 以安全、乾淨、明確為優先
- 動作要合理
- 避免尖銳危險器材成為視覺重點
- 表現「參與家事」而不是苦勞感
- 角色表情以願意嘗試、完成任務的正向感為主

---

# 8. Boss 規格

## 8.1 Boss 整體定位
Boss 不是可怕怪物，而是「孩子成長障礙的具象化」。
例如：
- 拖延魔王
- 分心怪
- 怕失敗巨獸
- 浪費小偷
- 衝動怪
- 懶懶龍

## 8.2 Boss 視覺規則
- 可以大、誇張、有記憶點
- 但不可恐怖
- 要像「可以被克服的挑戰」
- 顏色較主角鮮明，但不能陰暗壓迫
- 仍保持兒童可接受的程度
- 需要有故事性輪廓

---

# 9. 背景規格

## 9.1 章節背景
每個章節應有一個代表性場景，例如：
- 冒險營地
- 彩虹市集
- 時間王國
- 智慧圖書森林
- 成長山谷
- 勇氣山徑

## 9.2 背景要求
- 明亮
- 可辨識
- 具故事感
- 適合當首頁或章節頁背景
- 必須保留足夠空白區給 UI 疊加
- 不可讓資訊難以閱讀

# 13. 禁止事項總表

所有後續圖片製作，不得出現以下問題：

- 角色年齡感明顯漂移
- 主配色跑掉
- 圍巾消失
- 指南針徽章消失
- 狐狸肢體錯誤
- 角色變成另一種畫風
- 背景太複雜影響閱讀
- 太像戰鬥抽卡遊戲
- 太像廉價幼教素材
- 太寫實、太成熟、太性感、太陰暗
- 過度誇張表情導致不適
- 武器感過重
- 太像不同品牌或不同宇宙的角色

# 15. 驗收規則

一張圖能通過正式驗收，至少要符合：

- 一眼看得出是同一個世界觀
- 一眼看得出是既定角色
- 沒有解剖錯誤
- 沒有危險感或不適感
- 放進 UI 後不會搶走文字可讀性
- 適合 8 歲左右兒童
- 角色表情正向
- 色彩乾淨
- 可與其他圖並排仍保持一致

# 16. 結論

Real Life Quest 的美術核心不是炫技，而是：

> **讓孩子願意靠近、看得懂、記得住，並感覺自己真的在一個安全、溫暖、充滿成長感的冒險世界裡。**

之後所有新圖，不論是角色、任務圖、Boss 圖、背景圖、圖示，都必須服務這個核心目標。
