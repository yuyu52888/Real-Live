# Real Life Quest｜平板版 UI / UX Flow 規格書 v1.0

## 1. 產品定位
- 對象：8歲左右學童＋家長
- 載具：平板為主，優先支援直式操作
- 核心目標：讓孩子願意主動完成閱讀、英文、生活任務、運動任務、家事任務，並透過 RPG 化流程獲得成就感
- 操作原則：大按鈕、少層級、圖像明確、文字簡短、任務導向

## 2. 主要導覽架構
底部主選單 5 個：
1. 首頁 Home
2. 任務 Quests
3. 學習 Learn
4. 角色 Hero
5. 家長 Parent

## 3. 首頁 Home
### 畫面元素
- 角色頭像與等級、EXP 進度條
- 今日冒險摘要：今日 Boss、今日任務數、連續天數 Streak
- 三個快速入口：
  - 今日任務
  - 英文學習
  - 思維故事
- 今日鼓勵訊息
- 寶箱碎片數量
- 今日獎勵預告

### 主要操作
- 點「開始今日冒險」→ 進入任務總覽
- 點角色區 → 進入角色頁
- 點今日 Boss → 進入 Boss 挑戰頁

## 4. 任務頁 Quests
### 分頁
- 全部
- 閱讀
- 英文
- 運動
- 家事
- 隱藏任務

### 任務卡內容
- 類型圖示
- 任務名稱
- 一句簡介
- 難度星等
- EXP
- 需不需要家長確認
- 開始按鈕

### 任務詳情彈窗
- 任務目標
- 完成條件
- 動作要領 / 操作要領
- 圖示或插圖
- 安全提醒
- 開始任務按鈕
- 換一張任務卡按鈕（若有券）

## 5. 運動任務頁
### 顯示
- 任務名稱（例：跳繩100下）
- 大插圖
- 動作要領 3 點
- 安全提醒
- 計次提示（可手動加減）
- 完成按鈕

### 完成後
- 顯示成功動畫
- EXP + 能力值
- 是否掉落寶箱碎片
- 家長確認按鈕

## 6. 家事任務頁
### 顯示
- 任務名稱（例：整理書桌）
- 大插圖
- 操作步驟 3 點
- 安全提醒
- 拍照上傳（可選）
- 完成按鈕
- 家長確認按鈕

## 7. 英文學習頁
### 模式入口
- 今日新單字
- 今日複習
- 聽音找字
- 圖片選字
- 拼字挑戰

### 單字卡內容
- 英文單字
- 中文
- 圖片
- 發音按鈕
- 語速調整 0.60x~1.10x
- 例句
- 下一張

## 8. 思維故事頁
### 顯示
- 故事封面圖
- 標題
- 閱讀時間
- 內文分段
- 4 個想一想
- 1 個現實任務
- 完成閱讀按鈕

## 9. Boss 頁
### 顯示
- Boss 大圖
- Boss 名稱與章節
- HP 進度條
- 挑戰條件
- 三到五個進度節點
- 可獲得獎勵

### 完成後
- 勝利畫面
- 徽章
- 寶箱
- 章節解鎖提示

## 10. 角色頁
### 顯示
- 角色全身像
- 等級 / EXP
- 稱號
- 已裝備外觀
- 寵物
- 已解鎖背景
- 徽章牆

### 互動
- 更換帽子、披風、頭像框、背景、寵物
- 查看稱號條件

## 11. 獎勵頁 / 寶箱頁
### 顯示
- 寶箱碎片進度
- 可開啟寶箱
- 本次掉落物
- 權利型獎勵
- 任務券庫存

## 12. 家長模式頁
### 功能
- PIN 進入
- 審核任務完成
- 調整任務難度
- 啟用 / 停用物質獎勵
- 查看週報
- 查看連續紀錄
- 管理休息日
- 管理發音速度上限

## 13. 核心流程
### 每日流程
首頁 → 今日任務 → 完成 1~3 個任務 → 領 EXP / 碎片 → 視情況挑戰 Boss → 回角色頁看成長

### 學習流程
首頁 → 英文 / 故事 → 完成學習 → 小任務反思 → 領獎勵

### 家長流程
家長頁 → 審核任務 → 補發 / 調整 → 看週報

## 14. UI 視覺方向
- 風格：兒童友善、清爽、半扁平卡通 RPG
- 配色：柔和藍、綠、黃、橘；避免過度刺眼
- 元件：圓角卡片、大圖示、大按鈕、清楚進度條
- 文字：大字體、短句、少段落
- 圖片：每張任務卡有簡單示意插圖
