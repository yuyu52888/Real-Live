# Real Life Quest｜UI / UX Implementation Spec v1.1

## 0. 本版新增
- 首次使用加入「主角選擇」：男主角 / 女主角
- 兩位主角共享：
  - Lv / EXP
  - 任務
  - 稱號
  - 徽章
  - 帽子
  - 衣服
  - 披風
  - 背包
  - 寵物
  - 背景
- 角色性別只影響角色立繪、表情、動作動畫與對應服裝素材，不改變能力值或獎勵。

---

# 1. 視覺方向

## 1.1 風格
- 明亮、溫暖、兒童友善的奇幻冒險 RPG
- 主色：天空藍 / 草地綠 / 金黃色 / 暖橘
- 背景：城堡、森林、海岸、冒險營地等
- 卡片：淺米白紙張感 + 木牌標題
- 按鈕：高飽和藍 / 金黃，圓角，具立體感
- 圖示：大型、簡單、容易辨識

## 1.2 平板優先
- 第一優先：直式平板 4:3 / 3:4
- 同時支援橫式與手機尺寸
- 主要按鈕高度至少 56 px
- 主要文字至少 18 px
- 孩子閱讀內文 22–26 px
- 點擊區不得小於 44×44 px

# 2. 首次啟動流程

## Screen 01｜歡迎頁
內容：
- Real Life Quest Logo
- 「把真實生活，變成大冒險」
- 【開始冒險】

## Screen 02｜選擇主角
標題：
「選擇你的冒險角色」

左：
### 男主角
- 棕色短髮
- 冒險者服裝
- 紅橘色圍巾
- 活潑、勇敢表情

右：
### 女主角
- 棕色長髮或中長髮
- 冒險者服裝
- 紅橘色圍巾
- 活潑、自信表情

互動：
- 點角色 → 放大 + 金色光框
- 【就是他 / 她】
- 日後家長模式可重新選擇角色，不影響進度

## Screen 03｜角色名字
- 暱稱輸入
- 預設最多 12 字
- 【建立角色】

## Screen 04｜家長設定
- 4 位 PIN
- 每日任務量
- 運動 / 家事任務是否啟用
- 是否需要家長確認
- 英文語音預設 0.75x

- idle 正常站姿

- studying 英文學習

- chore 做家事
- tired 任務失敗 / 暫停
- surprise 寶箱
- walking 冒險
- portrait 頭像

服裝區域必須保留可替換：
- head
- body
- cape
- backpack
- accessory

# 14. 開發要求

- HTML / CSS / JavaScript
- PWA
- IndexedDB 優先
- Offline-first
- 可安裝到平板桌面
- 所有資料可匯出 JSON
- 不依賴伺服器即可完整使用 MVP
- Responsive
- 支援 touch
- 不使用 hover 作為唯一操作
- 動畫時間短，避免拖慢操作

# 15. 視覺參考優先級

GPT-6 開發時，依優先級實作：
1. 本規格功能與資訊架構
2. 已確認的 UI 模擬圖之布局與視覺風格
3. 內容資料 JSON
4. 通用兒童 UX 最佳實務

若模擬圖文字或數值與資料規格衝突，以 JSON / SPEC 為準。
